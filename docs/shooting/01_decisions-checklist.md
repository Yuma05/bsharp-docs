# 撮影企画で決めるべきこと

ショットリストから作らず、まず「何を決める必要があるか」を優先度・依存関係つきで整理する。「今決めるべきもの」と「後から決めればよいもの」を分ける。

## 今決めるべきもの（このドキュメントセットで確定させる）

土台になる順に並べている。上位が決まらないと下位が決められない。

| 順番 | 項目 | なぜ今か | 参照 |
|---|---|---|---|
| 1 | 写真の役割の整理（商品情報系／使用イメージ系／スタイリング系／ブランドイメージ系） | 全カットの目的分類。これがないと「なんとなく綺麗な写真」で終わる | [03](03_photo-categories.md) |
| 2 | 撮影全体の基本方針（光・色・背景・料理・人の気配・プロップ量） | ブランドの一貫性の土台。個別カットの判断基準になる | [02](02_visual-direction.md) |
| 3 | 商品×料理の組み合わせルール | 撮影当日に都度悩まないための判断軸。実商品未確定でも先に基準は作れる | [05](05_product-dish-pairing.md) |
| 4 | スタイリングルール（使う／使わない／使いすぎない） | プロップ・小物を毎回選定し直すコストをなくす | [06](06_styling-rules.md) |
| 5 | ECサイト側で必要な写真の洗い出し | 何をどこで使うかが決まらないと必要カット数が出せない | [04](04_site-shot-map.md) |
| 6 | 撮影効率の組み方（1セット→複数用途） | 限られた予算・日数で回すための撮影順序の設計 | [07](07_shoot-efficiency.md) |
| 7 | 初回撮影の優先順位（Must/Should/Nice） | すべてを一度に撮らないための絞り込み | [08](08_first-shoot-priority.md) |
| 8 | 撮影場所（自宅 or レンタルスタジオ） | F1（バックペーパー購入）の仕様・F2/F4の日数上限に直結 | [10](10_open-decisions.md) |
| 9 | 必要機材の過不足確認 | 既知なのは amaran pano 120c ×2・一眼のみ。三脚・レフ板等の要否は未確認 | [10](10_open-decisions.md) |

## 後から決めればよいもの（商品・体制が確定してから）

| 項目 | 何が決まれば確定できるか |
|---|---|
| 厳密なカット数・SKUごとの内訳 | B4（初期ラインナップ確定） |
| スタイリングカットの本数・組み合わせ数 | B4 ＋ 商品の色・形の実物確認 |
| 撮影日程の具体的カレンダー | B5（仕入れ発注）→ 入荷日、および撮影場所の決定 |
| 同一商品を複数個並べるカットの可否 | B5の発注数量（撮影用に確保できる数か） |
| 外部スタイリスト・フードコーディネーター起用の要否 | 体制・予算の確認（[10](10_open-decisions.md)） |
| Reel・広告用動画素材の本格運用 | Instagramフォロワー数・広告開始ゲート到達（[06_marketing-strategy.md](../business-plan/06_marketing-strategy.md)） |
| ギフト演出カット | ギフト需要が将来ターゲットとして視野に入る段階（[03_target-customer.md](../business-plan/03_target-customer.md) 5.） |
| 季節企画（「今月の器×旬の食材」）用の追加撮影サイクル | 初回撮影完了後、運用ペースが固まってから |
| Shopifyテーマ側の画像仕様（枚数上限・推奨解像度） | [99_pending.md](https://github.com/Yuma05/bsharp-thema/blob/main/docs/feedback/design/summary/99_pending.md)（C14）側の確認 |

判断の軸：**今決めるのは「繰り返し使えるルール」、後で決めるのは「今回の実行に必要な数字」**。ルールは商品が変わっても使い続けられるが、数字は商品リストが変われば作り直しになるため。
