# 目標とギャップ — なぜ現行モデルの延長線では届かないか

## 目標の定義

- **M36（開始36ヶ月目）に月間営業利益 ¥833,333（年換算¥1,000万）**
- 利益の定義は [財務モデル](../finance/03-pl-cf.md) と同じ営業利益: 貢献利益 − 広告費 − 固定費。
  報酬ゼロ・税引前・個人事業ベース（法人化・納税・自分の人件費は含まない。
  実際の手取り設計は達成が見えた段階で別途検討）

## 現行モデルをM36まで延長すると

[現行モデル](../finance/01-revenue-model.md)（セッション月+320・CVR改善・リピート3%）を
そのまま36ヶ月引き延ばした場合:

| 指標 | M36推定 |
|------|--------|
| セッション | 11,600/月（400 + 320×35） |
| CVR | ≈1.56%（1.2% + 0.011pp×33） |
| 注文 | ≈270/月（新規181 + リピート90） |
| 月商（送料込） | ≈¥162万 |
| 営業利益 | **≈¥25〜33万/月（年300〜420万）** |

- 上限の33万は自力出荷の場合。ただし月270件（日9件）の梱包・出荷は副業では現実的でなく、
  外注化（¥350/件）すると **実質25万前後**
- つまり延長線の着地は目標の **約1/2.5〜1/3**。「セッションを伸ばし続ける」だけでは届かない

## 構造的な壁: セレクト仕入れ・粗利40%の限界

貢献利益/注文 ¥1,320（掛率0.6・AOV¥5,090）を前提にすると、営業利益83万に必要な注文は
固定費を無視しても月630件超、月商320万超。この規模の集客（セッション3万超）は
うちる級のメディアが必要で、36ヶ月で到達した国内事例は確認できなかった。

参考事例が示す答えは「集客を伸ばす」と「1注文の粗利を厚くする」の両輪:

- **クラシコム（北欧、暮らしの道具店）**: 売上84.9億円・粗利率44.9%・営業利益率12.9%
  （2025年7月期）。粗利の源泉は**オリジナル商品比率55%**。セレクトのままなら成立していない
  （[ログミーFinance](https://finance.logmi.jp/articles/382595) /
  [日本ネット経済新聞](https://netkeizai.com/articles/detail/15024)）
- **マルヒロ（HASAMI）**: 産地問屋がブランド化（=自社企画・産地製造）+全国卸で
  年商8,000万→3億円（約8年）（[DRIVE](https://drive.media/posts/22274)）
- **中川政七商店**: SPA（製造小売）転換で20年で売上17倍・92.3億円
  （[ダイヤモンド](https://diamond.jp/articles/-/364548)）

## 逆算: M36に必要な構造

```
営業利益 ¥83万 = 貢献利益 ¥100〜110万 − 固定費 ¥17万
貢献利益 ¥100〜110万 の作り方（標準シナリオ）:
  自社EC(器+キッチン+食品)  月商289万 × 25.7% = ¥74万  … 利益の柱(68%)
  toB卸(OEM品・買取6掛)     月商 60万 × 24.3% = ¥15万  … 第2の柱(13%)
  Yahoo!+キナリノ           月商 50万 ×  9.0% = ¥4.5万
  楽天(ギフトセット型)       月商 80万 ×  7.0% = ¥5.6万
  eギフト(AnyGift/LINE)     月商 30万 ×  3.0% = ¥0.9万 … 利益でなく新規接点
  体験・ポップアップ         月商 10万 × 30%   = ¥3万
  タイアップ記事(月1本)      月商  8万 × 80%   = ¥6.4万 … 上振れ枠
```

ポイント:

1. **利益の8割は自社ECとtoB卸**。モールとeギフトは貢献率3〜9%しかなく、
   「利益を作る場所」ではなく「新規接点・指名検索の受け皿・ギフト需要の入口」
2. 自社ECの貢献率25.7%は、**OEM比率60%（実効掛率0.52）+ AOV¥6,000（セット化）+
   出荷外注¥350/件込み**の数字。現状構造（掛率0.6・AOV5,090）のままだと同じ月商でも
   貢献率は約19%まで落ち、営業利益は約20万下がって未達になる
3. toB卸は**フルOEM品（原価率≤0.40）でしか成立しない**（買取6掛が相場のため、
   原価率0.5では粗利が物流・手数料で消える）。OEMが卸の前提条件

## 必要セッションの現実性

| シナリオ | 自社EC注文 | 新規比率 | CVR | 必要セッション |
|---------|----------|---------|-----|--------------|
| 保守 | 300/月 | 65% | 1.5% | **13,000/月** |
| 標準 | 420/月 | 60% | 1.6% | **15,750/月** |
| 強気 | 532/月 | 58% | 1.8% | 17,151/月 |

- 現行計画のM12想定（3,920）の約4倍だが、36ヶ月かけて到達する水準としては
  現行の月+320ペースの延長（M36=11,600）+ Pinterest/SEOの複利で射程内
- CVR 1.6%は Shopify平均1.4%の上（[Littledata](https://www.littledata.io/ecommerce-conversion-rate)）。
  CVRの高いリピートチャネル（メール4〜5%、LINE開封55%）の比率を上げることで達成する設計。
  SNS流入だけでセッションを増やすとCVRが希釈され逆効果
- リピート比率40%は月次リピート率を現行仮説3%→3.5〜4%へ改善する前提
  （LINE ID連携顧客のLTVは非連携比1.8倍 — [Mico](https://mico-inc.com/blog/line-ec/)）

## 参考事例との整合性（この目標は無謀か）

| 事例 | 3年時点の規模 | 体制 |
|------|-------------|------|
| クラシコム | 月商1,000万（2010年末・3年目） | 専業2人＋スタッフ、後に8名 |
| うちる | （12年で）推定月商1,300〜3,000万・IG8.3万 | 出荷12名+制作5名 |
| **Bsharp目標** | **M36 全チャネル月商527万・自社EC 289万** | 副業＋出荷外注 |

- クラシコム3年目の約半分、うちるの1/4〜1/10。**「野心的だが前例レンジ内」**
- ただし両者とも専業。副業のまま到達した公開事例は確認できておらず、
  **実行上の最大リスクは資金でも市場でもなく工数**（[03-roadmap-36m.md](03-roadmap-36m.md) の
  外注化計画と再計画トリガーで管理する）

## 判定

- **標準シナリオ成立時: 年換算¥1,104万で目標達成**
- 保守シナリオ: 年547万。目標達成は M48 頃に後ろ倒し
- 施策はやるがOEMが失敗（セレクトのまま）: 年650〜750万で頭打ち
- 何もしない（現行延長）: 年300〜420万

つまり「達成できるか」は集客の上振れ運ではなく、**OEM移行・セッション4倍・外注化という
3つの構造変化を36ヶ月で完遂できるか**に懸かっている。各施策の詳細は
[02-initiative-playbook.md](02-initiative-playbook.md)、時系列は [03-roadmap-36m.md](03-roadmap-36m.md)。
