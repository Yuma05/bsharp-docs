# 36ヶ月ロードマップ — フェーズ・マイルストーン・M36の姿

前提: [01-goal-and-gap.md](01-goal-and-gap.md)（逆算構造）、
[02-initiative-playbook.md](02-initiative-playbook.md)（施策別の経済性とゲート）。
原則は **「ゲート制」= カレンダーではなく達成条件で次の施策を解禁する**。
目安月は標準シナリオ進行時のもの。

## フェーズ概観

```
Phase 0        Phase 1         Phase 2         Phase 3         Phase 4
M1−6           M7−12           M13−18          M19−24          M25−36
基盤づくり  →  PB化の助走   →  PB主力化     →  攻めの投資   →  多チャネル収穫
セット/ギフト   セミオーダーOEM   OEM比率30%      フルOEM(型起こし) toB卸 15−20店
献立コンテンツ  Yahoo!出店       キッチン用品     楽天(ギフトセット) サブスク/体験
Pinterest仕込み キナリノ問合せ   出荷外注(3PL)    食品セレクト      タイアップ記事
LINE登録導線    AnyGift(eギフト) ポップアップ     酒免許準備       OEM比率60%
```

## Phase 0（M1〜6）: 基盤づくり — 「集客を増やさず利益率を上げる」

| アクション | 内容 | KPI/ゲート |
|-----------|------|-----------|
| セット売り・ギフト訴求 | 2点目提案・献立/スタイリング記事・ギフト包装を開店時から標準装備 | セット率40%・AOV¥5,500 |
| Pinterest仕込み | IGコンテンツ転用で週10ピン。成果は1年後に出るので最初から | 累計300ピン |
| SEO | 現行計画（月2〜4本）を「豆皿」「取り皿 おしゃれ」等のロングテール+陶器市・作家記事に寄せる | 累計20本 |
| LINE/メール導線 | 同梱カード+購入後メールで登録率60%を狙う | 購入者100人でシナリオ配信開始 |
| 計測基盤 | セット率・ギフト比率・チャネル別セッションをダッシュボード化 | 月次レビュー定着 |

**Phase 0 出口条件（M6）: セッション2,000/月・月商28〜35万・セット率40%**
（現行モデルのM6=月商19万に対し、セット/ギフトのAOV効果で上振れさせる）

## Phase 1（M7〜12）: PB化の助走

| アクション | ゲート（解禁条件） | 内容 |
|-----------|-----------------|------|
| **セミオーダーOEM第1弾** | 単一SKUが月10〜20個×2〜3ヶ月連続 | 売れ筋の色替え/別注。版代1〜5万・MOQ30〜100個。産地（波佐見・美濃・有田）へ見積依頼はM7に開始 |
| Yahoo!出店 | 月商50万 or 工数確保 | 固定費ゼロの最小構成。ギフト検索の受け皿 |
| キナリノモール問合せ | 50SKU+ブランドページ完成 | 手数料を確認し、15%以下なら出店 |
| AnyGift（eギフト） | ギフト注文比率10%超 | Shopifyにeギフト実装。「住所を知らない相手に贈る」需要を取る |
| LINE/メール本格化 | 購入者200人 | 月2〜3回配信。新商品の先行販売（クラシコム初期の型） |

**Phase 1 出口条件（M12）: セッション5,000〜6,000/月・月商55〜75万・OEM第1弾完売・LINE友だち600**

## Phase 2（M13〜18）: PB主力化と体制づくり

| アクション | ゲート | 内容 |
|-----------|-------|------|
| セミオーダーOEM拡大 | 第1弾を3ヶ月で完売 | 四半期2〜3型追加、版流用でリピート発注。OEM比率30%へ |
| **キッチン用品セレクト開始** | 月間購入者200人 or セッション8,000 | 燕三条・堺の直取引で20〜30SKU（粗利40〜50%）。「"おいしい"を作る道具」棚 |
| **出荷外注（3PL/アルバイト）** | 月間出荷150件 | ¥350/件。副業の自力出荷限界を超える前に移行。浮いた時間はコンテンツとOEMへ |
| ポップアップ初出店 | 在庫60万+月商50万 | シェア型スペース・クラフトイベントで四半期1回。UGC・卸接点づくり |
| フルOEM・楽天の準備 | — | 定番SKUの月販データ蓄積、型起こし見積、楽天出店審査の下調べ |

**Phase 2 出口条件（M18）: セッション8,500〜10,000/月・月商120〜150万・OEM比率30%・営業利益25〜30万/月**

## Phase 3（M19〜24): 攻めの投資 — 資金と胆力の使いどころ

| アクション | ゲート | 内容 |
|-----------|-------|------|
| **フルOEM第1弾（型起こし）** | 定番SKU月50個×6ヶ月見込み+現金50〜100万 | 型代20〜30万+300個発注・半金前払い・納期6ヶ月。原価率0.40以下を交渉目標に |
| **楽天出店** | OEMギフトセット（AOV8,000超・粗利55%以上）10SKU | がんばれ!プラン（初期6万+月2.5万年一括）。ギフトKW特化・広告は売上の8〜10%上限 |
| **食品セレクト開始** | セッション12,000 or リピーター比率35% | 営業届出+食品衛生責任者。常温・賞味期限6ヶ月以上・20SKU。器×食品ギフトセット |
| 酒免許準備 | 蔵元2〜3社と取引成立 | 通信販売酒類小売業免許を申請（18〜20万・3〜4ヶ月）。証明書は蔵元発行 |
| LINEギフト直接出店 | eギフト月20件+ギフトSKU充実 | 審査申請。手数料次第で規模を決める |

**Phase 3 出口条件（M24）: セッション11,000〜13,000/月・月商190〜230万・フルOEM発売済み・営業利益40〜50万/月**

## 資金計画

現行の初期投資¥61.3万（推奨¥70万）に加えて、成長投資が段階的に必要になる:

| 時期 | 投資 | 金額目安 |
|------|------|---------|
| M7〜12 | セミオーダーOEM×2回（版代+MOQ100個×2） | ¥20〜40万 |
| M13〜18 | OEM拡大（四半期2〜3型）+ポップアップ+在庫積増 | ¥40〜70万 |
| M19〜24 | **フルOEM型代+300個（半金前払い）+楽天初期・年会費** | ¥80〜130万 |
| M25〜36 | フルOEM追加型+卸向け在庫+サブスク初期 | ¥60〜100万 |
| 合計 | | **累計¥200〜340万** |

- 原資は累計営業利益（M18時点で累計¥150万前後の見込み）で過半を賄えるが、
  **Phase 3の投資が先行するM19〜22に2度目の資金の谷**が来る。
  日本政策金融公庫の少額融資（¥100〜200万、無担保・新規開業枠）をM18頃に確保しておくと
  フルOEMのロット交渉（=原価率）で強気に出られる
- 在庫リスク管理: OEM発注は常に「直近実売の3〜6ヶ月分」を上限とする
