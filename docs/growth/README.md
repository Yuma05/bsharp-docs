# 成長戦略 — 36ヶ月で年間営業利益1,000万円

目標: **開始36ヶ月目に月間営業利益 ¥83万（年換算¥1,000万）**。
売上ではなく利益ベース。報酬ゼロ・税引前・個人事業の営業利益として定義する。

## 結論（先に要点）

**達成可能性: 条件付きで達成可能。** 標準シナリオで月間営業利益 ¥92万（年換算¥1,104万）。
ただし現行モデル（セレクト仕入れ・オーガニック集客のみ）の延長線では **年300〜420万で頭打ち**
であり、目標との差は約2.5倍。この差を埋める構造変化は次の3つで、**どれか1つでも欠けると未達**:

1. **OEM化（PB化）で粗利構造を変える** — セレクト仕入れ（掛率0.6・粗利40%）のままでは
   月商350万でも利益83万は構造的に出ない。クラシコムが粗利率44.9%を作った答えは
   「オリジナル比率55%」。Bsharpも M36 で自社EC売上のOEM比率60%（実効掛率0.52）が必要
2. **自社ECセッション 1.6万/月**（現行計画のM12想定3,920の約4倍） — SEO・Instagram・
   Pinterest・LINE/メールの4本柱。これはうちる（月間UU20万超）の1/10以下の水準
3. **出荷の外注化と工数設計** — M36の想定出荷は全チャネルで月700件超。副業の自力出荷限界
   （月150件前後）を M18 頃に超えるため、3PL/アルバイト化（¥350/件）を織り込み済み

| シナリオ | 全チャネル月商 | 貢献利益 | 営業利益/月 | 年換算 |
|---------|------------|---------|-----------|--------|
| 保守（セッション1.3万・OEM4割） | ¥311万 | ¥60万 | **¥46万** | ¥547万 → 達成はM48頃 |
| **標準（セッション1.6万・OEM6割）** | ¥527万 | ¥109万 | **¥92万** | **¥1,104万 → 達成** |
| 強気（セッション2.2万・OEM7割） | ¥718万 | ¥164万 | ¥144万 | ¥1,733万 |
