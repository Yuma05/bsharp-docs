## 確定が必要な項目

### 事業者情報（全文書共通・最重要）
- [ ] **運営責任者の氏名**（個人事業のため実名。屋号「Bsharp」＋氏名で表記）
- [ ] **住所・電話番号の扱い**（タスクメモ A8）：バーチャルオフィスで実表示 or 省略特例で運用（Shopify 自社 EC での特例適用可否を要確認。安全側はバーチャルオフィス）
- [ ] **メールアドレス**（ドメイン取得後・タスクメモ A3）
- [ ] **サイトURL／ドメイン**（タスクメモ C2）
- [ ] **LINE 公式アカウントの友だち追加URL／ID**
- [ ] 各文書の制定日・改定日

### 決済・配送
- [ ] 決済手段の最終確定（クレジットカード／コンビニ決済／銀行振込。Apple Pay 等 Shopify Payments 連動分の記載要否）
- [ ] コンビニ決済・銀行振込の支払期限日数
- [ ] 送料無料ライン（¥11,000／finance モデル）を導入するか
- [ ] 利用する配送業者・決済代行会社の確定（プライバシーポリシー §5）

### 返品
- [ ] 不良・破損の受付期限（例：到着後7日以内）
- [ ] 返金方法・返金までの目安日数
- [ ] **特商法表記の返品欄と return-policy.md の内容を一致させる**

### Cookie・外部送信（Shopify 設定と連動）
- [ ] 実際に設置するタグの確定（GA4／Meta Pixel／LINE 等）→ 未導入のものは cookie-policy.md の表から削除
- [ ] Shopify の「顧客プライバシー／Cookie 同意バナー」設定の有効化

## 実装上の注意（文書ではないが必須）
- **注文最終確認画面の表示**（特商法2022年改正）：分量・価格・支払時期・引渡時期・申込撤回に関する事項を確定直前に表示。Shopify チェックアウト設定で対応。
- **メルマガのオプトイン＋配信停止導線**（特定電子メール法）。
- **景品表示法・ステマ規制**：二重価格表示、PR 表記に注意。
