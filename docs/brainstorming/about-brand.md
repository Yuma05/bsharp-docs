# ブランドコンセプト/ブランドに込める思いを整理する

ブランドに込めた思い -> なぜやるのか・内側の気持ち・原点
ブランドコンセプト -> そもそも何者なのかや外向きのを定義

## とりあえず Bsharp に込める思いをざっと考える

### 思い

- 一人ひとりが自分の”おいしい”を見つけられるように
- ”おいしい”（食）を起点に人生のワクワク・発見が増えるように
- “おいしい”が自身の人生の中で探求したいテーマになるように（”おいしい”を突き詰めることが人生の一つの楽しみになるように）

### ひとり

- 旬の食材を楽しめるように
    - いつものルーティンだった買い物が新しい出会いを求めるワクワクになるように
- “おいしい”を作ることを楽しみ、食べることも楽しむことで自分で自分を満たせるように
    - ちょっと疲れた日でも自分の作る”おいしい”で自分を満たせるように
    - 自分自身で明日への活力を生み出せるように

### みんなで

- 自分の作る”おいしい”がみんなの思い出になるように
    - 誕生日やクリスマス、自分で作る”おいしい”がみんなのあたたかい思い出になるように
- 大切な人たちを自分の”おいしい”で満たせるように
    - 大切な人が疲れているときでも自分の作る”おいしい”で明日への活力を生み出せるように

### 今の”食”と照らして

- デリバリー/配食サービスの普及により、気軽においしいものにアクセスできるようになっている
    - 食にもコスパ・タイパが求められる時代
- 完全栄養食・ダイエットに迫られるような風潮がある中で、栄養素を数値で管理するようなものになっている

## いくつか問いを用意してみる

### 最近の価値観こんなとこ嫌だな（アンチテーゼ）

- キャリア
計画的にスキルや経験を獲得し、評価を受けるようなスタイル。
- 静かな退職
プライベートと仕事を完全に分けて、仕事は6割みたいな状態。
先述したキャリアが合わないとこうなる？
- 映える／ルッキズム
物事の表面にこだわりすぎる。
理想が手に入るまでの長い時間や手間に耐えられない。
理想や幸せの尺度を自分で決められず社会に流されている。
- 本当に好きなことを見つけるための労力を惜しんでしまう。
- 好きなことがあったとしても、それが仕事にならない／できない
→ 仕事／プライベートの分離につながる
- 宅食・配食など、気軽においしく栄養をとれるが、こだわっていない食
- ダイエットなど、数値で管理するような食
- 完全栄養食など、コスパ／タイパが求められている食
- 毎日必ず食事はするから、もっとこだわって”おいしい”を作って楽しんでほしい

### 「尖る」ってどういうこと？

- ゆずれない物／事がある
- 結果として他の人にワクワクを届けられる
    - 「おいしい」にこだわった人
    → 作ってあげる／お店に連れていってあげる
    - スノボ好きだった人
    → 新しい景色を見せてあげる／教えてあげる
    - etc...
- 暇がない
    - 常にやっていること／やってみたいことがある
- こだわりがある人
→ たくさん知っていて、実践している人、解像度が高い
- 面倒くさい人
→ 押しつけがましい、知っているだけ、解像度が低い
- 日々発見があること
    - 自分の“こだわり”による発見の連鎖がある
    （食 → 旬の食材 → 地域 etc...）
    - 日々の実践と発見で感覚が鋭くなること
- 小さな発見が、次のこだわりのテーマにつながる
- **発見と実践の積み重ねで、自分の感覚を磨き続ける**
- **発見は次のこだわりのテーマを生む**
- **たくさんのこだわりは、人生を豊かにし、他の人にワクワクと、こだわりのキッカケを与える**

### 食器は“おいしい”を見つける上でどんな役割を果たす？

- 食に興味を持ちはじめる一つのきっかけ
- せっかくご飯を自分で作っているのに…
    - 味が決まらない
    → レシピなどのブログ
    - おいしそうに見えない
    → 食器・盛り付けなどのブログ
- 自分でご飯を作るとき、最後のアウトプットが食卓。
- 食卓の完成度を高めることで自信を持ち、自分自身に満足し、次の”おいしい”へとつなげる。
- 提供された側の喜び／反応もよりよくなり、次の”おいしい”につながる。
- 食材 → 作りたいもの → 食器
食器／食卓 → 作りたいもの
双方向に“おいしい”を作るきっかけになる。
- お気に入りの食器ができると、料理にもこだわれるようになる？
    - いつもにちょっと一手間。火入れ、盛り付け。
