## 1. 前提のおさらい

**トーン**：「おいしい」にこだわる友人。詳しいけど偉そうじゃない、感覚的だけど根拠がある。

**コンテンツの型（3つ、06で確定済み）**
1. 器 → レシピ（この器に盛るための料理）
2. 器 → 旬の食材・産地（この器に合わせたい季節の食材）
3. 器 → 作り手・素材の背景（なぜこの器なのか）

**主なチャネル**：Instagram（開設済み・E1完了）／ Pinterest ／ SEO・ブログ ／ LINE・メール

**想定する2人**（[03_target-customer.md](../business-plan/03_target-customer.md)）
- にぽちゃん：1人暮らしOL・自炊は気分次第・かわいい器に出会う時間がない
- くれあ夫婦：在宅の日の夜ご飯・ナチュラル系・長く使えるデザインを求めている

---

## 2. 型①「器 → レシピ」のアイデア

- 同じ一皿を「平日ver（時短・楽ちん）」「休日ver（ちょっと丁寧）」で盛り替えて見せる
- 「洗い物がめんどくさい日の大皿レシピ」→ くれあ夫婦の悩み（取り分け大皿）に直結
- 「一人分でも様になる盛り付け」→ にぽちゃんの悩み（かわいく盛れない）に直結
- 器のサイズ・深さ別レシピシリーズ（小皿には副菜、深皿にはシチュー等）
- 「余り物リメイク」×器替えで“ちゃんと作った感”を出す回
- 季節の行事ごはん（誕生日・クリスマス・お花見）を器で格上げする回
- お酒に合う一皿（くれあ夫婦の「ご飯とお酒」の習慣に寄せる）

## 3. 型②「器 → 旬の食材・産地」のアイデア

- 「今月の器」×「今が旬の食材」を月1で紹介するシリーズ化
- 産地つながりの器と食材をペアで紹介（同じ地域の窯元と旬の食材）
- スーパーの野菜売り場での「なんとなくの買い物」を器目線で言語化する投稿（B案：ブランドの目的にある「なんとなくの買い物が、旬の食材との出会いになる」を直接絵にする）
- 「この器を買ったら、次は何を作る？」をQ&A/コメント企画にして食材提案につなげる

## 4. 型③「器 → 作り手・素材の背景」のアイデア

- 窯元・作り手の紹介（顔が見える一言コメント＋制作風景）
- 「なぜこの器を選んだか」をBsharp目線で語るキャプション企画（選定基準は[04_product-lineup.md](../business-plan/04_product-lineup.md)）
- 素材・技法の豆知識（土もの/磁器、釉薬の違いなど）を1投稿1トピックで
- Before/After：同じ料理を「なんとなくの器」と「選んだ器」で並べて違いを見せる

## 5. 型をまたぐ・フォーマット別アイデア

**Instagram**
- リール：盛り付けのビフォーアフター、器に盛るまでの数十秒
- フィード：器単体の物撮り＋キャプションで背景を語る（型③）
- ストーリーズ：「この器、どう使う？」募集→フィードで回答（双方向導線、06の「食材から器へ戻る導線」に対応）

**Pinterest**
- 「器 × 料理」の完成写真をピン中心に、ブログ/EC商品ページへの導線として使う
- シーン別ボード（朝ごはん／おもてなし／お酒の肴）

**SEO・ブログ**
- 「器の選び方」系の検索意図に答える記事＋自社器を自然に紹介
- 型①②③をロングフォームでまとめた保存版記事

**LINE・メール**
- 新作入荷や「今月の器×旬の食材」ダイジェストの定期配信
- 器が届いた人向けに「早速使ってみたレシピ」を送るフォローアップ

## 6. ペルソナ別に刺さりそうな切り口
