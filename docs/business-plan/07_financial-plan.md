# 売上・費用計画

短期（〜18ヶ月）の収益・費用・資金計画。36ヶ月の成長戦略は [09_growth-roadmap.md](09_growth-roadmap.md) に分離している。
財務モデル一式（収益構造の分解・コスト方程式・月次PL/CF・xlsx）は [../finance/](../finance/README.md) を参照。

前提：全額自己資金（融資・調達なし）／2人での副業／報酬ゼロで組む／数値は標準シナリオ。

## 1. ゴールと必要資金

| 項目 | 数値 |
|------|------|
| 月商ゴール | **¥300,000 @ 12ヶ月目**（副業として手応えを測るライン） |
| 必要自己資金 | **¥612,800**（M0 の資金の谷）→ 予備込み推奨 **¥700,000** |
| M12 見込み | 月商 ¥392,825（商品売上 ¥33.5万でゴール達成。保守シナリオでは ¥21万で未達） |
| 18ヶ月累計営業利益 | +¥92.8万（累計CF +¥13.3万・**M17 で投資回収**） |

営業利益は M1 からほぼ黒字（固定費が月 ¥8,820 しかないため）。ただし儲けの大半は成長のための在庫（M18 時点 ¥68.5万）に化けるため、判断は PL ではなく CF とセッション実測で行う。

## 2. 主要な意思決定（2026年7月）

| 論点 | 決定 | 根拠 |
|------|------|------|
| 初期仕入れ | 縮小・回転型 ¥440,000（主力10SKU×10個 + 他20SKU×5〜6個） | 現案600個・¥120万は販売計画未接続のまま重い |
| 集客構造 | オーガニック（IG/YouTube/ブログ内製）中心 | 掛率0.6の粗利構造ではコールド広告 CAC ¥20,000 ≫ 許容CPA ¥1,850 で不成立 |
| 送料無料ライン | ¥11,000（未到達は全国一律 ¥880 顧客負担） | 高ライン＝送料収入・貢献利益を最大化（到達率≈0%） |
| 特商法表記 | 自宅住所を公開 | バーチャルオフィス費用なし |

全項目（広告・送料キャリア・EC基盤を含む8論点）は [../finance/README.md](../finance/README.md) の「主要な意思決定の記録」を参照。

## 3. 撤退・再計画の判断

**PL ではなく、セッション実測 vs 計画（月 +320）で判断する。** 営業利益は固定費の小ささゆえ早期から黒字に見えるため、事業の伸びの実態はセッションで測る。

## 4. リスク・未確定事項

- **掛率0.6 は全件交渉未確定**（仕入れ候補101件中61件が交渉中△、卸値列は空欄）。最重要感度変数。0.65 に悪化すると貢献利益/注文が約 ¥255 減る
- **送料無料ライン ¥11,000 は到達率≈0% の「送料収入ライン」**。貢献利益は最大化するが、送料負担がカゴ落ち要因になり CVR/売上を毀損しないかが最大の未検証リスク。開店後にカート放棄率・到達率・平均点数を実測し、悪化の兆候があれば ¥9,900/¥8,000 への引き下げを判断
- 人気ブランド系は卸審査で落ちる可能性 → SKU構成のプランBを意識
- リピート率 月3% は強気仮説（年20%相当に置くと M12 月商 −約 ¥2.2万）
- 返品送料・キャンセル規約は未設計（[../policy/return-policy.md](../policy/return-policy.md) と連動）
- 国内仕入れのみなら許認可不要。輸入する場合は食品等輸入届が必要
