## 1. 基本方針 — オーガニック中心

**コールド広告では成立しない**というのが出発点。掛率0.6の粗利構造では、コールド広告の CAC ¥20,000 が許容CPA ¥1,850 を大きく上回る。

したがって集客は **Instagram・YouTube・ブログを内製するオーガニック**を主軸に置く。

| 項目 | 方針 |
|------|------|
| 主軸 | オーガニック（IG / YouTube / ブログ内製） |
| 広告 | Meta 一択・月 ¥10,000・リタゲ中心 |
| 広告の開始ゲート | オーディエンス 1,000人到達時（目安 M3）。年末繁忙期は初実験を避ける |
| 撤退・再計画の判断 | PLではなく**セッション実測 vs 計画（月 +320）** |

## 2. 器起点メディアの役割

世の中のレシピメディアの多くは、食材・料理を起点にしています。Bsharp のメディアは**「器起点」でレシピと食材を提案**します。

器が売り物であると同時に、次の「おいしい」の入口になる——物販とメディアは、この一点でつながっています（[02_brand-concept.md](02_brand-concept.md) 2.）。

発信のトーンは「『おいしい』にこだわる友人」（[02_brand-concept.md](02_brand-concept.md) 4.）。詳しいけれど偉そうではなく、感覚的だけれど根拠がある。「この器なら、いつもの料理が少し違って見えるかもしれない」「この季節なら、こんな食材を合わせても楽しいかもしれない」という提案の形をとります。

### コンテンツの型（案）

| 型 | 内容 | 資産の出どころ |
|----|------|--------------|
| 器 → レシピ | この器に盛るための料理 | 自作 |
| 器 → 旬の食材・産地 | この器に合わせたい季節の食材 | 自作 |
| 器 → 作り手・素材の背景 | なぜこの器なのかを語る | [04_product-lineup.md](04_product-lineup.md) 選定基準4で整理した情報 |

3つの型はいずれも「器 → 次の料理」の一方向に閉じず、食材から器へ戻る導線も設計する（双方向に「おいしい」を作るきっかけにする）。
