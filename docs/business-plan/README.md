## ブランドの骨格（3行）

- **ミッション**：自分の「おいしい」にこだわり続ける人を増やす
- **何者か**：自分の「おいしい」にこだわり続けるための、器のセレクトショップ＋器起点のレシピメディア
- **つながり**：器が売り物であると同時に、次の「おいしい」の入口になる
