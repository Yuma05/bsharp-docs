# ブランドコンセプト

Bsharpという名前には、「尖り、こだわり続けよう」という思いを込めています。

たくさんの情報や選択肢に触れられる今だからこそ、自分の心が動くものを、自分の感覚で選ぶことを大切にしたいと考えています。

何度も食べたくなる味や、思わず手に取りたくなる器。日々の自分の感情を大切にし、自分なりの「好き」を深めていく。私たちにとって"尖る"とは、そこから生まれるこだわりを楽しみながら育てていくことです。好きなものが増えるほど、毎日はもっと自分色に染まり、明るくなると信じています。

私たちは、食べることが大好きです。食べることには、いつも新しい発見があります。

旅先で初めての味に出会ったり、その土地の食材やシェフの感性が表れた一皿に触れたりすると、とてもワクワクします。一方で、自分のために作る毎日のごはんにも、それと同じくらい大きな楽しさがあります。栄養や味のバランスを考えながら料理を作り、ひと口食べて「今日のごはん、めちゃくちゃおいしい」と思えた日は、それだけで心が満たされます。

料理に合わせて器を選ぶ時間も、食べる楽しさの一部です。いつもの料理でも、盛りつける器が変わるだけで、驚くほど生き生きとして見えることがあります。器は料理を引き立てながら、その人の個性や、その日の気分まで映してくれる、食卓のファッションのような存在だと考えています。

何をおいしいと感じるのか、どんな味に心が動くのか。食事を重ねるうちに、自分の「大好きな味」が増え、日々に彩りが生まれていくはずです。

Bsharpは、毎日使いやすく、料理の魅力を引き立てる器を届けます。
すっきりと凛とした佇まいの中に、手仕事の温かさが感じられるもの。食卓に自然と馴染み、使うたびに少し心が弾むものを丁寧に選んでいきます。

器を手にしたとき、「このお皿には何を盛ろう」「次は何を作ろう」と、自然に料理のことを考えてもらえたら嬉しいです。

一人ひとりが自分の感覚で味を選び、自分なりの工夫で料理を楽しめるようになること。
食と器を通じて、大好きな味が増え、生活することそのものがもっと楽しみになるきっかけを届けていきます。
