# ターゲット顧客

> ペルソナは以前作成したペルソナ資料からの書き起こし。一次/将来ターゲットの位置づけ整理は引き続き暫定版。

## 1. ターゲット像（ペルソナ）

### ペルソナ1：1人暮らし 20代女性

**プロフィール**
- にぽちゃん（24歳）
- 都内で働くOL・中野に住んでいる
- 1人暮らし歴2年目

**ライフスタイル**
- 週4回ほど都内のオフィスに出勤して、週1回在宅
- 予定がない場合は自炊して夜ご飯を済ませる
- 会社の飲み会は比較的多め
- 土日は恋人が家に来たり、一緒に出かけたりしている

**食生活の特徴**
- たまに食べたいものがあるときは丁寧に作ったりする、うまく作れたりした時はインスタに記録としてあげたりする
- 普段は適当に済ませる（？）
- お菓子や甘いもの、スイーツなども好き
- カフェも好き
- 本当はもう少し高頻度で自炊したい！

**食器への価値観**
- かわいい食器が見つかったら欲しいと思っている
- 家があまり広くないので、枚数は厳選してお気に入りだけ持ちたいと思っている

**悩み・課題**
- かわいいお皿にあまり出会えない！お皿のために買い物に行く時間はない！

**その人の生活のどこに器が入り込むか**
- 予定のない土日ができたら、パンを作ったり、丁寧なご飯を作って盛り付けたりする
- 写真映えもするとテンションも自己肯定感も上がる
- もうちょっと仕事頑張ろうって思える

### ペルソナ2：2人暮らし 20〜30代新婚夫婦

**プロフィール**
- くれあ夫婦（25歳と30歳？）
- 旦那さんも奥さんも週2回ほど在宅の日がある

**ライフスタイル**
- 7割くらいは奥さんが料理をする
- 残業多め、2人ともちょっと夜型
- お酒が好きなので、ご飯を作った日はお酒を合わせて飲むこともある

**食生活の特徴**
- シチューなど放置して作りやすい＆メイン1つでもいけるものをよく作る？
- たまにフルーツなども食べてる
- 洗い物がめんどくさいので、大皿に盛って取り分けることも多い

**食器への価値観**
- かわいい食器が見つかったら欲しいと思っている
- ビビットカラーなものよりも馴染みやすいナチュラル系のものが好き
- 2つずつ買いたい
- 目立たないけど品があっておしゃれ、って感じのものが好き

**悩み・課題**
- 長く使い続けられるデザインの気に入ったお皿が欲しい

**その人の生活のどこに器が入り込むか**
- 在宅の日の夜ご飯
- お家で過ごす雨の日の休日

## 2. 一次ターゲット — 料理を「もう一段」楽しみたい人

週に数回は自炊していて、レシピを検索したり、食器売り場でつい足を止めたりする。器に興味はあるが、選ぶ自分なりの基準はまだ持っていない。料理は嫌いではない、むしろ好き。ただ、日々の忙しさの中で、せっかく好きな料理が作業になりかけている——そんな人が、Bsharp の最初のお客さまです。

この層に対して Bsharp が提供するのは、器そのものよりも「選ぶ基準」です。なぜこの器なのかを語れること（[04_product-lineup.md](04_product-lineup.md) の選定基準）と、器起点のレシピ提案（[06_marketing-strategy.md](06_marketing-strategy.md)）が、その基準づくりを助けます。

### 届けたい変化

- なんとなくの買い物が、旬の食材との発見の場になる
- 義務感で作っていた料理が、自分と向き合い、自分を取り戻す時間になる
- 自分の「おいしい」が、大切な人の支えや喜び、あたたかい記憶につながることに気づく

## 3. 将来ターゲット — 料理が義務になっている人

料理を負担や作業として捉えていて、器を選ぶ余地を感じていない層。

この層に Bsharp が直接届くことは初期には想定しません。器の価値を訴えても、まず料理そのものが負担になっているため響きにくいと考えています。

## 4. 一次から将来への広がり方

一次ターゲットの食卓・贈り物・発信が、料理を義務と感じている人にとっての「きっかけ」になる。こだわる人の輪を通じて、間接的に広がっていくことを目指します。
