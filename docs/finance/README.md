# Bsharp 財務モデル

木村義弘『事業計画の極意 ― 仮説と検証で描く成長ストーリー』の収益構造分解法に沿って作成した、
収益構造の分解 → コスト方程式 → 月次PL/CF の一式。内部用。

前提条件:

- 全額自己資金（融資・調達なし）→ CFの目的は「資金の谷の深さ = 必要自己資金額」の把握
- 2人での副業（1人は1ヶ月を目処に退職->フルコミット判定）。報酬はゼロで組む（ただし投下時間は記録する。撤退/継続判断と値付けの歪み防止のため)
- すべての数字に根拠ラベル（実測・調査・仮説）を付け、開店後の実測で置き換える

## モデルの使い方

- **感度分析・数値変更**: xlsx の「前提」シートの**青字セル**を直接編集（Excel / Google Sheets）。
  全シートが数式連動しているので再生成は不要。シナリオ係数 0.6 / 1.0 / 1.4 で保守/標準/強気を切替
- **構造変更**（行追加・ロジック変更・期間延長）: `python3 docs/finance/build_financial_model.py` で再生成。
  **xlsx は上書きされる**ので、手で加えた変更はスクリプト側に反映してから実行すること

## 結果ハイライト（標準シナリオ）

- **必要自己資金 = ¥612,800**（M0の資金の谷）→ 予備込み推奨 **¥70万**
- M12 月商 **¥392,825**（商品売上¥33.5万でゴール達成。保守シナリオでは¥21万で未達）
- 営業利益はM1からほぼ黒字（固定費が月¥8,820しかないため）。18ヶ月累計営業利益 **+¥92.8万**
  に対し累計CFは **+¥13.3万**（**M17で投資回収**）— 儲けの大半は成長のための在庫（M18時点¥68.5万）に
  化けるが、高い送料無料ラインで送料収入（現金）を厚く取る分、¥8,000案（回収18ヶ月超）より現金回収が早い
- 撤退判断はPLではなく **セッション実測 vs 計画（月+320）** で行う

## リスク・未確定事項

- **掛率0.6は全件交渉未確定**（仕入れ候補101件中61件が交渉中△、卸値列は空欄）。最重要感度変数。
  0.65に悪化すると貢献利益/注文が約¥255減る。取引実績による段階改善（1年後0.55など）は交渉テーマ
- **送料無料ライン¥11,000は到達率≈0%の「送料収入ライン」**。貢献利益は最大化するが、送料負担が
  カゴ落ち要因になりCVR/売上を毀損しないかが最大の未検証リスク（02が元々¥8,000を推した理由）。
  開店後にカート放棄率・到達率・平均点数を実測し、CVR悪化の兆候があれば¥9,900/¥8,000への引き下げを判断
- 人気ブランド系は卸審査で落ちる可能性 → SKU構成のプランBを意識
- リピート率 月3%は強気仮説（年20%相当に置くとM12月商 −約¥2.2万）→ 実測で要検証
- 返品送料・キャンセル規約は未設計。国内仕入れのみなら許認可不要（輸入する場合は食品等輸入届が必要）
