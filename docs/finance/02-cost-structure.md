## 変動費の方程式（1注文あたり）

```
貢献利益/注文 = 注文額 × (1 − 掛率)                    … 粗利
             − (注文額 + 顧客負担送料) × 3.55%         … 決済手数料
             − 資材単価(サイズ連動)                     … 梱包資材
             − 送料の店側ネット負担                     … 到達注文=実費全額 / 未到達=実費−¥880
             − 注文額 × 破損率                          … 破損・不良引当
```

| パラメータ | 値 | 根拠 |
|-----------|-----|------|
| 掛率 | 0.6 | 仮説（相場5〜6.5掛け）。**全件交渉未確定・感度分析対象** |
| 決済手数料 | 3.55% | 確定（Shopify Payments Basic・国内カード） |
| 送料実費 | 1点¥870 / 2点¥1,082 / 3点+¥1,183 | 調査済み（ゆうパック・加重平均・割引後） |
| 顧客負担送料（未到達時） | ¥880 全国一律 | 設計値（60サイズ実費≒転嫁。沖縄・離島は別建て検討） |
| 梱包資材 | 1点¥250 / 2点¥320 / 3点+¥420 | 仮説（サイズ連動。ikkaモデルは¥150想定 — 実勢見積で要確定） |
| 破損・不良率 | 1.5% | 仮説（配送破損の再送=原価+送料2回分、検品不良含む） |
| 仕入れ時送料 | 発注1回あたり¥2,000仮置き | 仕入れ先ごとの条件で置換 |

## 送料無料ラインの最適化

### モデル: ラインが購買行動を変える

- 無料ライン到達を狙った「もう1点買い」で注文構成が変わる（AOV押し上げ）
- カゴ落ち理由の筆頭は送料 → ラインの有無・高さがCVRに効く（仮説補正）

### 計算結果（M12・セッション3,900の月・実勢送料）

| シナリオ | AOV | 到達率 | 貢献/注文 | 貢献率 | 月商 | 月間貢献利益 |
|---------|------|-------|----------|--------|------|------------|
| なし（一律¥880） | ¥4,740 | 0% | ¥1,228 | 25.9% | ¥184,860 | ¥47,899 |
| ¥5,000 | ¥5,340 | 60% | ¥886 | 16.6% | ¥270,738 | ¥44,939 |
| ¥8,000 | ¥5,090 | 23% | ¥1,125 | 22.1% | ¥238,212 | ¥52,655 |
| **¥11,000** | ¥5,034 | 5% | ¥1,279 | 25.4% | ¥225,775 | **¥57,356** |

CVR仮説: なし1.0% / ¥5,000→1.3% / ¥8,000→1.2% / ¥11,000→1.15%（ベース1.2%への補正）

### 最終決定: **¥11,000**（顧客負担¥880・全国一律）

**月間貢献利益が最大（¥57,356）のラインを採る。** 到達率≈0〜5%の高ラインは「もう1点買い」の
行動誘発をほぼ捨てる代わり、ほぼ全注文から送料¥880を収入として取り込み、送料無料による粗利の
食い込みをなくす。財務モデル（バケット据え置き・到達率0%）でも貢献利益/注文は¥1,125→**¥1,320**に上がり、
月商（送料込）はM12で¥379,507→¥392,825、18ヶ月の投資回収が¥8,000案の「18ヶ月超」から**M17**へ
前倒しになる（[03-pl-cf.md](03-pl-cf.md)）。

採用理由:

1. **貢献利益・現金回収を最大化する。** 送料収入は現金なので、CFの谷から早く抜ける効き目が大きい。
   薄利・報酬ゼロの副業ECでは「1注文の利益を厚くする」ことが集客の弱さを補う一手になる
2. **器はサイズ課金がなく重量無関係。** 高ラインでも送料実費は¥870〜1,183で頭打ち → 顧客負担¥880で
   ほぼ相殺でき、店側の送料ネット負担が小さい。到達を狙わせて送料を店側が被る¥5,000案（貢献率16.6%・
   最下位）とは逆の設計
3. **下振れ時の逃げ道がある。** CVRを毀損したら段階的に引き下げれば戻せる（後述）

**この選択の最大リスク（旧・¥8,000採用理由の裏返し）**: ¥11,000は3点セット（≈¥8,800）でも届かない
実質形骸ラインで、購買行動を誘発しない。送料負担がカゴ落ち要因になりCVRを下げれば、表の「なし」
（¥47,899・最下位級）方向に転落する。¥8,000は「利益とCVRのバランス型」で下振れが限定的、¥5,000は
「売上最大・利益最小」（到達60%で送料負担が粗利を食い貢献率16.6%）。¥11,000の優位は「高ラインでも
CVRが落ちない」という仮定に依存している点を忘れないこと。

開店後の検証: カート放棄率・無料ライン到達率・平均点数を月次で実測し、CVR悪化の兆候が出たら
¥9,900 → ¥8,000 への段階的な引き下げを判断する。逆に到達率が想定より出るなら、セット提案の
訴求で送料無料到達を積極的に狙わせる設計にも寄せられる。
