# 収益構造の分解（トップライン）

決定済みの前提:

- 月商ゴール: **¥300,000 @ 12ヶ月目**
- 集客: オーガニック内製（Instagram / YouTube / ブログ、ゼロから立ち上げ）+ 知人・コミュニティ告知
- 初期仕入れ: 縮小・回転型（約220個 ≈ ¥44万）
- 送料無料ライン: ¥11,000（到達率≈0%の送料収入最大化ライン。決定経緯は [02-cost-structure.md](02-cost-structure.md)）

---

## 売上方程式（KPIツリー）

```
月商 = 新規注文数 × AOV + リピート注文数 × AOV + 送料収入

新規注文数   = オーガニックセッション × CVR(org)
             + リタゲ注文（広告費 ÷ CPC × CVR(rt)）
             + 知人ブースト（M1〜M2のみ）
リピート注文数 = 累計購入者数 × 月次リピート率
AOV         = 注文構成バケット（1点/2点/3点+）の加重平均
送料収入     = 無料ライン未到達注文 × 顧客負担¥880
```

### 広告の経済性 → 事業構造の帰結

- 許容CPA = 貢献利益 × LTV補正（×1.4）≈ **¥1,850/新規顧客**
- コールド広告のCAC = CPC¥100 ÷ CVR0.5% = **¥20,000** → **乖離約11倍で構造的に不成立**
- 成立条件 `CPC÷CVR ≤ ¥1,850` は CVR5.4% または CPC¥9 を要求（どちらも非現実）

月商30万円は「広告で買う」のではなく **「月4,000セッション前後を呼べる自社メディアを12ヶ月で作る」**
ことで達成する。これが本モデルの最重要仮説。広告はリターゲティング（CVRが桁違い・唯一採算圏）と
実測データ購入に限定し、**Meta一択・月¥10,000・統合オーディエンス1,000人超えゲートで開始**（目安M3）。

- 参考: 器は低頻度・非消耗品でLTVが伸びにくく、広告が回るD2C（LTV2〜3万円のリピート型）と構造が違う。
  セット販売・ギフト・レビュー蓄積で許容CPAが改善すれば、広告の採算ラインは動く → 実測を続ける意味
